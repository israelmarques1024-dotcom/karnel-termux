# Freebuff

A free AI coding agent for the terminal.

**Package:** freebuff
**Official:** https://freebuff.com
**Type:** AI coding agent (npm)

## Install

```bash
karnel install ai --freebuff
```

## Uninstall

```bash
karnel uninstall ai --freebuff
```

## Update

```bash
karnel update ai --freebuff
```

Freebuff is installed from its official npm package and is available as the
`freebuff` command.
