# Goose CLI

**Goose** is an open-source AI coding agent from the Agentic AI Foundation (Linux Foundation). It operates in your terminal to plan, write, test, and ship code.

- **Official Site:** https://block.github.io/goose/
- **GitHub:** https://github.com/aaif-goose/goose
- **License:** Apache 2.0

## Usage

```bash
goose session          # Start interactive session
goose configure        # First-time setup
goose --version        # Show version
```

On Termux, Goose runs inside a proot-distro Ubuntu container for glibc and X11 library compatibility.
