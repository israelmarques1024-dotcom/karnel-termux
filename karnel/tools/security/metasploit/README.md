# Metasploit Framework

Penetration-testing framework installed from the package or built from the Rapid7 repository fallback.

- Install: `karnel install security --metasploit`
- Update: `karnel update security --metasploit`
- Reinstall: `karnel reinstall security --metasploit`
- Uninstall: `karnel uninstall security --metasploit`
- Primary executable: `msfconsole`
