# enum4linux

SMB enumeration tool installed from the package or the CiscoCXSecurity repository fallback.

- Install: `karnel install security --enum4linux`
- Update: `karnel update security --enum4linux`
- Reinstall: `karnel reinstall security --enum4linux`
- Uninstall: `karnel uninstall security --enum4linux`
- Executable: `enum4linux`
