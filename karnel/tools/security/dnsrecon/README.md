# DNSRecon

DNS reconnaissance tool installed from the package or the DNSRecon repository fallback.

- Install: `karnel install security --dnsrecon`
- Update: `karnel update security --dnsrecon`
- Reinstall: `karnel reinstall security --dnsrecon`
- Uninstall: `karnel uninstall security --dnsrecon`
- Executable: `dnsrecon`
