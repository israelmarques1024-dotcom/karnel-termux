# WAFW00F

Web application firewall detection tool installed from the package or Python package fallback.

- Install: `karnel install security --wafw00f`
- Update: `karnel update security --wafw00f`
- Reinstall: `karnel reinstall security --wafw00f`
- Uninstall: `karnel uninstall security --wafw00f`
- Executable: `wafw00f`
