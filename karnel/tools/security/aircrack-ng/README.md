# Aircrack-ng

Wireless security suite installed from the `aircrack-ng` package.

- Install: `karnel install security --aircrack-ng`
- Update: `karnel update security --aircrack-ng`
- Reinstall: `karnel reinstall security --aircrack-ng`
- Uninstall: `karnel uninstall security --aircrack-ng`
- Executable: `aircrack-ng`
