# Burp Suite Community Edition

Web security testing application installed from the package or the Community Edition JAR fallback.

- Install: `karnel install security --burpsuite`
- Update: `karnel update security --burpsuite`
- Reinstall: `karnel reinstall security --burpsuite`
- Uninstall: `karnel uninstall security --burpsuite`
- Executable: `burpsuite`
