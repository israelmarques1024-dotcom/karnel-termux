# theHarvester

Open-source intelligence collection tool installed from the package or the project repository fallback.

- Install: `karnel install security --theharvester`
- Update: `karnel update security --theharvester`
- Reinstall: `karnel reinstall security --theharvester`
- Uninstall: `karnel uninstall security --theharvester`
- Executable: `theharvester`
