# OWASP Amass

Attack-surface mapping tool installed from the package or an OWASP Amass release binary fallback.

- Install: `karnel install security --amass`
- Update: `karnel update security --amass`
- Reinstall: `karnel reinstall security --amass`
- Uninstall: `karnel uninstall security --amass`
- Executable: `amass`
