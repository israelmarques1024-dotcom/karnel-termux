# Tamagotchi

Python terminal game downloaded from the configured Tamagotchi source.

- Install: `karnel install games --tamagotchi`
- Update: `karnel update games --tamagotchi`
- Reinstall: `karnel reinstall games --tamagotchi`
- Uninstall: `karnel uninstall games --tamagotchi`
- Executable: `tamagotchi`
