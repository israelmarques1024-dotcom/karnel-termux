# Bun

JavaScript runtime installed as a native ARM64 glibc build or through an Ubuntu proot container.

- Install: `karnel install lang --bun`
- Update: `karnel update lang --bun`
- Reinstall: `karnel reinstall lang --bun`
- Uninstall: `karnel uninstall lang --bun`
- Executables: `bun`, `bunx` (native installation)
